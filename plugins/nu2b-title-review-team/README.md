# 高级职称评审专家团（nu2b-title-review-team）

按《南昌大学第二附属医院专业技术职务评聘实施办法（2024年修订）》（院字〔2024〕71号）第四条，镜像医院**专业技术职称评聘工作组**12 个部门的 Team 型专家团，用于高级职称申报的资格预审、业绩分口审查、评分模拟与政策咨询。

## 类型

Team 型（多角色协作团队，1 名主理人 + 12 名部门专家）

## 功能

- **资格预审**：学历资历、执业与考试有效期、基层服务、工作周数、业绩成果三项门槛、代表作五审三中、延期申报负面清单
- **业绩分口审查**：按文件规定的业绩界定分工各口把关——医疗类（医务处/病案科/行风办/门诊部/院感处/药学部）、教学类（教务处）、科技类（科技处/临床试验研究中心）、护理类（护理部）
- **评分模拟**：医药技 = 专业技术 50% + 科研创新 30% + 教学业绩 20%；护理 = 护理技术 60% + 教学 + 科研；自然科学研究系列 = 科研 85% + 教学 15%；副系列 = 综合条件 80% + 科研 15% + 学术任职 5%
- **政策咨询**：单维度问题由对应部门专家直接作答，不需启动完整团队

## 使用示例

- 我是卫生系列申报人员，请帮我做一次高级职称申报资格预审
- 请按12个部门分口审查我的业绩材料，并模拟业绩评分
- 代表作五审、业绩成果三项条件和答辩要求分别是怎么规定的？
