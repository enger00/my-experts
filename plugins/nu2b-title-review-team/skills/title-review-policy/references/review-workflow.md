# 南昌大学第二附属医院高级职称评聘工作流模式

> 依据：院字〔2024〕71号《南昌大学第二附属医院专业技术职务评聘实施办法（2024年修订）》  
> （含附件1卫生系列评聘方案、附件2自然科学研究系列评分标准、附件3副系列评分标准）  
> 适用：卫生系列高级（正高/副高）评聘，其他系列参照执行

---

## 一、文件精神要点（读懂规则再动手）

1. **一套办法、三个附件、三种通道**：卫生系列"自主评审、评聘结合"（院内评委会）；教学/科研系列送南昌大学评委会；其他系列送省指定评委会。
2. **双门槛约束**：既看任职条件（学历资历+工作经历+业绩成果），又受**岗位设置结构比例**限制，两条线都要过。
3. **两评价体系并行**：门槛条件（业绩成果三项以上，第1项专题报告必备）决定"能不能报"；业绩评分（百分制加权）决定"排第几"。
4. **时间窗铁律**：资历、业绩、学历均计算至**评审上一年 12 月 31 日**；实践能力水平考试成绩 **3 年有效**。
5. **代表作规则**：三项成果代表作送审，五审三中方可申报；共同第一作者只认排名第一，共同通讯只认最后一位；**论文复制比不得高于 30%**；评分论文须本院为第一完成单位。
6. **公示三次、每次五个工作日**：资格审查后公示（含业绩公展）→ 业绩评分公示 → 拟聘及推荐名单公示 → 评审结果再公示，全程阳光操作。

## 二、可复制工作流（申报人主线，六阶段）

```
阶段0 自查预判 → 阶段1 材料筹备 → 阶段2 科室推荐与申报
→ 阶段3 资格审查+代表作送审 → 阶段4 公示与业绩评分
→ 阶段5 竞聘答辩 → 阶段6 评审聘任
```

### 阶段 0｜资格自查（启动期，申报前 3~6 个月）

- [ ] 核对学历资历：正高=本科以上+副高满5年+**已取得副教授资格**（工龄满30年者2025年起执行）；副高=本科+中级满5年，或大专+中级满7年（限主管护/技/药）
- [ ] 确认执业资格与申报专业、执业范围一致（医疗/护理类须注册）
- [ ] 实践能力水平考试成绩在 3 年有效期内
- [ ] 继续教育学时达标
- [ ] 副高申报（执业医师）：县级以下或对口支援服务累计满 1 年
- [ ] 工作量达标：正高年均专业技术工作≥35周，副高≥40周（对照附表1~8，附表为扫描件需逐项核对）
- [ ] 近五年年均讲授专题课：正高≥3次，副高≥2次（备单位证明）
- [ ] 排查延期申报负面清单（见第四节），确认不在影响期内
- [ ] 业绩成果项数盘点：取得现资格以来 ≥3 项（第1项专题报告必备）
- [ ] **关口 G0**：以上全部通过才进入阶段1；不满足者评估"破格"（学科初审+医技委/学术委预审）或"绿色通道"（援外/援疆/留学回国/抗疫一线/直通车）

### 阶段 1｜材料筹备（对照院内表格逐件准备）

- [ ] **《高级专业技术职务评聘申请表》**（附件2）——个人基本信息、学历资历、业绩概述
- [ ] **《代表作送审表》**（附件3）——自选 3 项标志性业绩送同行专家五审
- [ ] **专题报告 1 份**：≥2500字，含题目/姓名/单位/材料/方法/结果/讨论，选题为任现职期间 1~2 项高水平业务，全部可溯源、文献注明出处，**附原始资料**
- [ ] **病案/技术工作报告 5 份**：本人主持、反映专业水平，单位审核盖章（无病床科室提交病案分析材料）
- [ ] **业绩印证材料**：按《业绩印证材料目录》（附件4）编目——论文（含检索证明、原始资料）、课题（《立项合同书》+《结题/验收报告》+对应论文，缺一不可）、专利证书、获奖证书、专著教材（ISBN+CIP+字数佐证）、学术任职聘书、新技术新项目奖励文件等
- [ ] **《任现职以来的工作情况表》**（附件6）——工作量、年度考核、行风情况
- [ ] **抗疫成果专题报告**（附件5，仅抗疫一线人员适用）
- [ ] 专题课授课证明：时间、地点、对象、人数、内容
- [ ] 临床类专业：至少 1 篇本专业**临床型**代表作
- [ ] **关口 G1**：每份业绩均可溯源（原件或盖章复印件）；时间窗全部落在"现资格以来至评审上一年12月31日"

### 阶段 2｜科室推荐与个人申报

- [ ] 向**本科室**提交评聘申请 → 科室同意推荐
- [ ] 向**人事处**提交《评聘申请表》及全套材料
- [ ] **产出**：正式进入当年度评聘程序

### 阶段 3｜资格审查 + 成果代表作送审

- [ ] 人事处牵头资格审查（学历、资历、执业、工作量、负面清单）
- [ ] 未取得相应资格者：三项代表作**五审**（同行专家鉴定）
- [ ] **关口 G3**：五审中 ≥3 审评议合格，方可继续
- [ ] 通过者向**医院职称评聘工作组**（人事处、纪委监督检查室、医务处、病案科、行风办、教务处、科技处、临床试验研究中心、护理部、门诊部、院感处、药学部）提交业绩材料
- [ ] **业绩界定分工**：医疗类→医务处/病案科/行风办/门诊部/院感处/药学部；教学类→教务处；科技类→科技处/临床试验研究中心；护理类→护理部

### 阶段 4｜公示公展与业绩评分

- [ ] **第一次公示**：资格审查通过名单 + 业绩公展，5 个工作日
- [ ] 工作组按评分标准业绩评分：
  - 医药技系列：专业技术 50% + 科研创新 30% + 教学 20%（荣誉条件另加5分）
  - 护理系列：护理技术 60% + 教学 + 科研（限护理/院感方向）
  - 自然科学研究系列：科研 85% + 教学 15%
  - 副系列：综合条件 80% + 科研 15% + 学术任职 5%
- [ ] **第二次公示**：业绩得分，5 个工作日
- [ ] **关口 G4**：公示异议处理完毕、排名确认

### 阶段 5｜竞聘会（现场分组评分）

- [ ] 参加**医院专业技术岗位竞聘会暨卫生高级专业技术资格评审推荐委员会**
- [ ] **正高申报人、破格申报人必须答辩**；副高按当年方案执行
- [ ] 委员会根据业绩评分排名 + 现场评分，产生**拟聘人员名单**和**推荐参评人员名单**
- [ ] **第三次公示**：拟聘及推荐名单，5 个工作日

### 阶段 6｜评委会评审与聘任

- [ ] 被推荐人员参加**医院卫生高级专业技术资格评审会**（封闭式评审）
- [ ] 评审方式：业绩评分排名 → 现场评审 → **实名差额投票** → 得票数达总票数 2/3 及以上、在职数范围内者为通过
- [ ] **第四次公示**：评审结果，5 个工作日
- [ ] 无异议 → 报送主管部门**审批备案** → 在岗位结构比例范围内**聘任**相应职务

## 四、风险防控：延期申报负面清单（任现职以来）

| 情形                   | 延期年限  |
| -------------------- | ----- |
| 年度考核基本合格 / 医德考评"一般"  | 1 年   |
| 年度考核不合格 / 医德考评"较差"   | 2 年   |
| 医疗事故次要责任 / 拒不完成指令性任务 | 1 年   |
| 医疗事故完全或主要责任          | 3 年   |
| 收受"红包""回扣"（查实）       | 1–3 年 |
| 索取"红包""回扣"（查实）       | 3 年   |
| 重大教学事故               | 2 年   |
| 违反师德师风               | 1–3 年 |
| 伪造学历资历业绩、违反科研行为道德规范  | 3 年   |
| 意识形态问题造成严重不良影响       | 1–3 年 |

> 延期计算：已满基本申报年限的自情形出现时起算；未满的自满年限时起算。同一事项多种情形取最长，不同事项累计。

## 五、关键规则备忘

1. **业绩时间窗**：取得现资格以来 → 评审上一年 12 月 31 日；工作量从聘任时间起算。
2. **岗位变动**：医药护技四类岗位间变动，须取得现岗位同级职称且受聘满 1 年方可申报高一级；任职年限可累加。
3. **论文认定**：核心期刊=《中文核心期刊要目总览》（以发表当年收录为准）；SCI 以南昌大学图书馆检索证明为准；国家级/省级期刊按《江西省卫生高级职称评审医学杂志分级汇总表》；增刊、特刊、专刊、专辑、清样稿不算。
4. **课题认定**：须同时具备《立项合同书》《结题/验收报告》原件 + 相应论文；立项单位须为本院。
5. **临床试验**：I–III 期注册为目的的多中心试验（2023年1月1日后结题）；BE、体外诊断试剂、IV 期不可作门槛条件，只可计分。
6. **"直通车"**：如以第一/通讯在 CELL/Nature/Science/Lancet/NEJM/JAMA 主刊发表论文等 10 项国家级业绩之一，可在岗位比例内直评直聘。
7. **破格通道**：学历业绩不达标但能力特别优秀者 → 专业学科初审 → 医院医疗专业技术委员会或学术委员会预审 → 破格申报（必须答辩）。
