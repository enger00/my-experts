# 三类"重复 / 共用"判定

**务必分清三种情况，用户口径（2026-10-18）：要的是"不同申报人使用同一篇论文/课题/奖励"的标识，不是同一人多个槽位。**

| 类别 | 定义 | 审核含义 | 视觉 |
|------|------|---------|------|
| ① **跨申报人共用同一成果** | 不同的人拿同一篇论文/同一课题/同一奖励申报 | 多为正常合作（共同作者、课题参与人），**只提示不判错** | 紫底白字角标「与孙万磊共用」+ 顶部红汇总条 |
| ② **同一人多槽位共用同一份原件** | 一个 PDF 挂在本人 2 个槽位 | 多为合法合并件，**可忽略** | 灰标「⧉ 同原件×N」 |
| ③ **同一人同成果占多个槽位** | 同一成果填进"其他代表作1"+"其他代表作2" | **占名额凑数，审核价值最高** | 尚未加角标（待定夺），出清单 |

## ① 跨申报人共用（`_cross_groups()`）

- **聚类**：并查集 + `_same_item()`，`_name_key()` 归一化（去空白 / 标点 / 引号并小写）
- ⚠ **绝不能用名称精确相等**。同一成果不同人填报写法常不一致——熊鸣填 `…treatment A review`、孙万磊填 `…treatment Medicine`（把刊名填进标题尾），归一化后仍一字不同，精确相等必然漏。
- **三档判据**：
  1. 完全相同
  2. 前缀包含（较短者 ≥ 20 字，填表截断常见）
  3. 4-gram 覆盖率 ≥ 0.85
- **性能**：按 (类型, 归一化名前 12 字符) 分桶后桶内两两比，避免 750 条 O(n²)（28 万次）；结果模块级缓存，实测 0.07 s
- **`person_detail()` 回填**：`cross_n` / `cross_people`（含姓名+工号），`b['跨人共用条数']`
- ⚠ **专题报告必须跳过** `_cross_banner()`：`ityp` 统一成"专题报告（门槛必备）"，否则全员互相命中
- **展示口径（2026-10-18 定）**：角标**直接写出对方姓名**，不写"N 人共用"。
  - 1–2 人：`与孙万磊共用` / `与沈浩、罗磊共用`
  - ≥3 人：`与张三 等 N 人共用`
  - 复用同一 `_who()` 函数供顶部汇总条与名称列角标共用；`title` 保留完整"姓名（工号）"清单
- **现状**：17 组 / 35 人次（论文 7、课题 7、专利/教学/奖励各 1）→ `_跨申报人共用成果清单.csv`
- 最大一组：课题「吸烟通过 IL-33/ST2 途径活化肝星状细胞促进肝纤维化」沈浩 / 熊鸣 / 罗磊 3 人

## ② 同人多槽位共用同一原件

- `person_detail()` 按 doc_id 分组回填 `dup_slots` / `dup_n`，`b['重复使用组数']`
- ⚠ **必须按 person_key 过滤**，否则跨人共用会误报
- 现状 30 组

## ③ 同人同成果占多个槽位（2026-10-18 新发现）

- 脚本 `_scan_selfdup.py` → `_同人重复申报清单.csv`
- **15 组**：王美秀、万琳、段甜甜、付凯文、王燕、胡白娥、熊鸣、朱海琴、胡俊文、邓名山、万冬花（2 组）、胡文英、郭丽君、魏际穷
- 典型形态：「论文N + 其他代表作N」填同一个题目
- ⚠ 名称归一化须排除 `否 / 无` 这类无效值（工号 07059 两条都填"否"，会被误判为重复）

## 串档修复工具链（多槽位共用同一 doc_id 的真错配）

```
_scan_dup_doc.py --csv   # 4-gram 覆盖分档：合并件 / 疑似错配 / 需人工
        ↓
_pick_cand.py --csv      # 在本人材料目录（原件材料 + 已转码）找候选原件
        ↓
_apply_cand.py [--apply] [--warn] [--only=工号]   # 改指（默认 dry-run）
        ↓
python _build_p1.py && _upd_journal.py --apply && _recn_affil.py --lang en|cn --apply
```

- `_apply_cand.py` 自动备份主库、补登 pdf_doc、同步 paper_meta、清 pdf_p1
- ⚠ **引用件陷阱（最大坑）**：申请表 / 检索证明 / 查新报告 / 目录 / 专题报告里**逐条列着代表作标题**，4-gram 覆盖率能到 **1.00**，曾被当成原文排第一（唐小平 4 个槽位被"建议改指"到申请表）。
  候选筛选必须先用 `_CITE` 正则排除，并要求正文长度 **≥ 1200**：

  ```python
  _CITE = re.compile(r'申请表|申报表|评审表|…|检索证明|检索报告|查新|证明'
                     r'|目录|清单|汇总|公示|专题报告|述职|…|封面|说明|通知'
                     r'|模版|模板|样式|封面页|扉页')
  ```

- ⚠ 候选文件名含**别的申报人姓名**时标"须人工确认"（按 pdf_link 全量姓名库比对，**不要用中文连续片段猜**，会满屏误报）
- 现状：37 组 → 31 组；已改指 9 条（陈未平、谢亮×2、黄松、夏忠彬、黄佳兵×2、董香丽、邹海啸）；剩余多为扫描件/未转码，只出清单不自动改
