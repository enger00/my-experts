# 路由判据与题名清洗

## 一、路由决策树

判据来源优先级（从上到下）：

```
1. 显式来源字段
   source = 'cnki_export'            → 知网
   wf_rid 非空                        → 万方
2. 落地页域名（url_src_json 里的 url 取 host）
   cnki.com.cn / kns.cnki.net        → 知网
   wanfangdata.com.cn                → 万方
   yiigle.com                        → 中华医学期刊
   cqvip.com                         → 维普（未实现）
   zhangqiaoip.com                   → 掌桥（未实现）
3. 刊名特征
   中华医学会系列刊                   → 中华医学期刊
4. 语种/来源
   英文库迁入 / 题名无汉字 / DOI 前缀  → 英文出版社通道
5. DOI / PMID
   OA 刊 DOI、PMID + PMCID 齐全       → OA 通道
────────────────────────────────────────────
6. 以上全无                          → 题名搜索通道（占 63%）
```

### 关键事实：63% 无来源线索
实测自 **4,221 条**缺口池，最大的一维不是"哪个数据库"，而是
**「有 id/链接（可直取）vs 只有题名（必须搜索）」**：

| 形态 | 占比 | 处置 |
|---|---|---|
| 无任何来源线索 | **63%（2,667 条）** | 只能靠**题名搜索**，逐通道试 |
| 有 id / 链接 | 37% | 按域名直取 |

⇒ 排工时前先看这一刀，别把 63% 当"少数难例"。

## 二、题名清洗（唯一实现）

⛔ **唯一出处 `tools/_cn_title_norm.py`**，`CLEAN_VERSION=2`。
任何脚本需要清洗题名，一律 `from _cn_title_norm import clean_title`，**禁止再写第四份实现**。

### 规则（按执行顺序）

1. **反复 `html.unescape` + 去标签，直到稳定**（嵌套实体如 `&amp;lt;` 需多轮）
2. 清 `_RESIDUE` 半截标签残留
3. 去首尾 `_TAIL`：`[.．·…]`（含前导省略号——旧实现漏掉这一条，实测差异 **169 条**）

### ⛔ 勿删的字符
`T>A` / `G>C` 这类**基因变异的 `>` 是合法字符**，不可一刀切删尖括号。
（残留检查时曾发现 2 条，人工确认为正常内容。）

### 自检
```bash
python tools/_cn_title_norm.py     # 8 例断言，须 8/8 通过
```

### 消费方
| 脚本 | 用法 |
|---|---|
| `_cnki_gap_pick.py` | 取数前清洗，用于快照比对 |
| `_cnki_retry_clean.py` | 以 `clean_title` 为基座，再加知网特化步骤（字面 `rn`、错字表、未闭合括号、副标题切分） |
| `_cnki_unavailable_ledger.py` | 自愈条件 (c) 用它比对快照 |

## 三、结构性难例（必须从分母里扣掉）

全库学术期刊缺口 **3,572 条**中，**1,042 条（29.2%）结构上搜不出来**：

| 类型 | 条数 | 原因 |
|---|---|---|
| 带 HTML 标签 | 158 | 题名里混标签，检索必不匹配 |
| 英文篇名 | 145 | 中文库里用英文题名检索中文库 |
| 被截断 | 739 | 题名不完整，无法定位 |

⇒ 算"可下载量"时的分母应是 **3,572 − 1,042 = 2,530**，不是 3,572。

## 四、题材判定（别只看一个字段）

⛔ `doc_type` **不可信**：会议论文的"来源会议"曾被写进 `journal_name` 而 `doc_type` 仍标期刊
（漏判 171 条）。**判体裁须「字段判据 + 名称特征判据」双轨**。

- 判中文刊看 **DOI 归属**，不看刊名拼写
- 判报纸用**结尾词 + 白名单**（含"报"的 223 条里 **90 条是学报**，不是报纸）
