# 结算口径与核验

> 原则一句话：**只认库内数字变化**。通道自报的增量一律视为"待核验"。

## 一、四分类（必须平）

| 类 | 含义 | 口径 |
|---|---|---|
| **A** | 既有全文 | `pdf_status=1`，**去重** |
| **B** | 本轮新增 | 结算前后 `pdf_status=1` 之差（去重） |
| **C** | 仍未获取 | 缺口（去重，排除结构性难例） |
| **D** | 排除 / 去重 | `exclude_flag=1` ∪ `dup_of IS NOT NULL` |

**硬判据：A + B + C + D = 总数**。不平即核验失败，不得出报告。

```bash
python tools/_audit_now.py
```

## 二、去重闸门（不可省）

```sql
-- 所有统计必须带这一条
WHERE COALESCE(dup_of,0)=0
```

⛔ **「已下载 PDF 全文」也必须去重**：重复行与其来源行**共用同一个 PDF 文件**，
不过滤＝同一篇数两遍。**实测曾虚高 140（7,971 → 7,831）**。

英文库当前同路径重复组数为 **0**，但**新增去重机制时必须回归此检查**。

展示层统计一律用 **`carrier_type`**（`app.py` 09-20 起全面切换），
`doc_type` 只作抓取源旁证、**不进任何统计**。统一闸门 `cn_dedup_expr(conn)`（无 `dup_of` 列自动降级恒真，旧备份库不 500）。

## 四、数值与字符串防坑

- `pub_year` 混空串 ⇒ 一律 `CAST(... AS INTEGER)` **且** `TRIM(...)<>''`
- SQL 里拼 `TRIM(title)<>''` 时注意：**曾因三引号包裹（`''''`）被截断**导致
  `OperationalError` ⇒ 去掉该条件重跑即可
- ⛔ **「字段有值」≠「值是对的」**：同刊同年出现两个卷号时，先查库内 `journal_name`/`pub_year`
  与 PDF 实体是否相符（**账实不符**），**不要默认是解析器 bug**
- 老旧 PDF 文本层汉字本身会错（南昌→**南吕**），正则无解 ⇒ 用**库内同字段值建词表自校验**

## 六、不可得台账治理

```bash
python tools/_cnki_unavailable_ledger.py --show 15
```

### 确定性失败分类（命中即排除，重试必再失败）

| 类别 | 判据 | 含义 |
|---|---|---|
| `hard` | 「无可点结果行」 | 无全文下载入口 |
| `soft` | 「检索无结果」 | 题名截断 / 含标签 / 未收录 |
| `mismatch` | 「刊物不符」 | 首屏 20 行里只有**他刊**同名题名，本刊那行**不在首屏** |
| `repeat` | 未知形态重复 ≥3 次 | 兜底：防将来新形态再卡死取数 |

### 三条自愈（放回池）
1. 已下载（`pdf_status=1`）
2. 补了中文题名
3. **库内题名「清洗后」≠ 台账快照**

⛔ 第 3 条必须用 `clean_title` 比对：库内原始题名带 `<em>`，直接跟快照比会把已排除条目**立刻误放回**。

### ⛔ 只认 `hard`/`soft` 的后果（实测教训）
`mismatch` 从不入账 ⇒ 取数每轮又拿到同几条，各连试 3 次、**第 2 片刚跑 4 条就熔断**，
续跑永远推不动。补上 `mismatch` + `repeat` 兜底后，台账 11 → **19** 条，取数头部即可正常推进。

> `mismatch` 的真解是给 worker 加**翻页**（本刊行多在第 2 页）——待办增强，做之前先确认 CDP 空闲。

### 幂等复验
台账更新后**必须复跑一次**，第二次应报 **0 变化**，否则说明自愈条件不稳定。

## 七、备份与回收

```bash
python tools/_backup_db_online.py cn.db <标签>   # 回填前必做
python tools/_backup_prune.py                    # 滚动剪枝
python tools/_trash_file.py <文件> --yes         # 删除一律走回收站，不用 rm
```

⛔ 一次性重置类脚本必须有**独立台账**，不能靠状态位判幂等；⛔ **绝不写进守护参数**。

⛔ **严禁用 bash 重定向（`>`/`>>`/heredoc）写 `.workbuddy/` 下的中文路径**：
会「从 0 偏移覆盖」⇒ **字节数不变、内容静默损坏**。
安全写法：Write/Edit 工具，或 Python `open(p,'w',encoding='utf-8',newline='\n')`；**写完必须回读校验**。
