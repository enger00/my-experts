# 回归用例 · 生信多组学科研团

版本：1.0.0 ｜ 建立日期：2026-09-08 ｜ 维护：易云

用途：验证专家团协作链路（主理人调度 → 成员产出 → 回传汇编）与单点能力均未漂移。
团队型回归除业务结果外，还需验收协作规范、科研严谨性红线与依赖技能可用性。

---

## R1 · GSE75010 子痫前期胎盘多组学复现（全流程）

- **触发输入**：基于 GSE75010 复现子痫前期胎盘多组学分析，给出完整流程与图表
- **预期路由**：主理人按 Workflow B 调度
  `omics-data-acquisition → omics-analysis-engineer → omics-statistics-analyst
  → omics-annotation-specialist → omics-visualization-engineer → omics-report-writer`
- **业务预期产出**：数据来源与 QC 结论、差异分析结果、统计稳健性说明、功能注释、图表、可复现清单
- **验收标准**：
  1. 明确给出 GSE75010 的平台信息、分组设计与样本量，**不臆造**
  2. 每个数字可追溯到具体阶段产出
  3. 交付包含数据版本、软件版本、关键参数与随机种子
- **判定**：□ 通过　□ 不通过

## R2 · 单细胞 RNA 测序分析

- **触发输入**：做单细胞 RNA 测序质控、聚类、细胞类型注释与标志基因筛选
- **预期路由**：主理人 → `omics-analysis-engineer`（必要时先经 `omics-data-acquisition`）
- **业务预期产出**：QC 结论、聚类结果、细胞类型注释（含标记基因与参考数据集）、标志基因表
- **验收标准**：
  1. 细胞类型注释给出所用标记基因与参考数据集，未凭空命名
  2. 明确写出质控阈值与过滤前后细胞数
  3. 提示批次效应风险（若存在）
- **判定**：□ 通过　□ 不通过

## R3 · 两样本孟德尔随机化

- **触发输入**：做两样本孟德尔随机化分析，输出敏感性分析与森林图
- **预期路由**：主理人 → `omics-statistics-analyst`（深度档），拉入 `omics-visualization-engineer` 出图
- **业务预期产出**：工具变量来源与强度、效应量与置信区间、异质性与多效性检验、森林图
- **验收标准**：
  1. 报告效应量、置信区间、p 值三者齐全
  2. 明确检验工具变量假设（F 统计量、多效性）
  3. 结论边界清晰，未把关联写成因果
- **判定**：□ 通过　□ 不通过

## 协作规范验收（每次回归必查）

1. 主理人先执行 TeamCreate，再 spawn 成员
2. 成员通过 SendMessage 回传主理人，主理人未代写成员产出
3. 跨成员信息流经主理人中转，无成员间直连
4. Agent 工具的 `name` 与 `subagent_type` 均传入成员 Agent ID（非中文名）

## 科研严谨性红线验收

1. 无编造的数值、基因名、通路名
2. 无编造的参考文献；无法核实的已标注"需人工核对"
3. 相关与因果表述区分正确
4. 不确定性（多重检验、批次、样本量）已显式说明

## 依赖技能可用性验收

重跑 `skill-asset-audit` 的 `scan_skills.py` 更新索引，再重跑 `gen_team_dependencies.py`，
比对 `skill_dependencies.json` 中的 94 个技能是否仍然存在。
任一依赖技能消失即视为不通过，需更新对应成员 MD。

## 上下文预算验收

1. 每个 Phase 只加载本阶段所需技能，未出现全量技能罗列
2. 成员 turns 未超过 60，主理人未超过 120
3. 汇编阶段未重复展开成员原始产出全文

---

## 回归执行要求

1. 成员提示词、SOP 或依赖技能变更后，回归 R1—R3
2. 协作规范、严谨性红线任一不通过，即判定该轮整体不通过
3. 结果留档，保留最近 5 次
