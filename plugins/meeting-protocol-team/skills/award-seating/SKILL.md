# 科教大会颁奖排表

输入两件事，输出四张表。全流程脚本化，下一年只需换两份 docx。

## 输入 / 输出

| | 内容 |
|---|---|
| 输入 1 | 大会议程 `.docx`（含"与会领导""颁奖仪式"两段） |
| 输入 2 | 表彰明细 `.docx`（含获奖科室/人员、奖励标准） |
| 输出 1 | `{年}年科教工作大会颁奖领导排位及领奖顺序.xlsx` —— 6 个工作表：座位排布表 / 领导排位图(发放顺序) / 领奖顺序图 / **桌牌打印单** / **桌牌打印单(领导)** / **礼仪分工表**；后五表全部公式引用座位排布表，改座位表即全表联动 |
| 输出 2 | `data.json` —— 中间数据，人工核对点 |
| 配套 | `assets/打印模版.docx`（Word，含 `MERGEFIELD "姓名"`，1×2 表格，楷体 sz180） |
| 可选 | `build_print.py` 加 `--with-print` 另出独立 `打印单_…桌牌.xlsx`（旧流程，主表已内置打印单，一般不需要） |

## 步骤

### Step 0 — 环境
需要 `openpyxl`、`python-docx`。本机已就绪，直接用隔离 venv：
```
C:\Users\Dell\.workbuddy\binaries\python\envs\default\Scripts\python.exe
```
不要用系统 Python。文件被占用时先请用户关闭预览；脚本已有 `_新` 后缀兜底。

### Step 1 — 一键跑（推荐）
```bash
python scripts/run_all.py --agenda 议程.docx --detail 明细.docx --outdir 输出目录
```
默认会在解析后**停下来等人工核对 data.json**（非交互环境自动继续），加 `--auto` 跳过停顿。

常用参数：`--first-seat-row 4`（礼堂前 3 排留空）、`--seats-per-row 6`、`--leader-rule school_first|doc`、`--duty-style compact|full`、`--with-print`（另出独立打印单文件）。

### Step 2 — 人工核对 data.json（关键，不可跳过）
脚本解析是启发式的，以下四项必须人眼过一遍：
1. `leaders` 座次顺序：1 号居中（最高领导），奇数号在左、偶数号在右
2. `awards` 是否只含本部门负责发放的奖项（教学类环节应落在 `excluded_agenda` 里）
3. `items` 中 `name: "待定"` 的领奖代表，会前补报
4. `meta`：标题 / 时间 / 地点 / 主持人 / `scope`（如"科技处发放部分"）/ `extra_notes`（特例说明，如"某领导本人上台领奖需由他人代领"）

### Step 3 — 分步跑（需要精细控制时）
```bash
python scripts/parse_inputs.py --agenda 议程.docx --detail 明细.docx --out data.json
python scripts/build_tables.py --data data.json --out 三表.xlsx
python scripts/build_print.py --src 三表.xlsx --template assets/打印单模板.xlsx --out 打印单.xlsx
```

### Step 4 — 出桌牌
桌牌打印单已并入主表（「桌牌打印单」= 领奖人 A:C + 领导 D 列；「桌牌打印单(领导)」= 单列领导姓名），全部公式引用座位排布表。用 `assets/打印模版.docx` 做邮件合并：领奖人数据源选「桌牌打印单」A:C 列，领导桌牌选「桌牌打印单(领导)」。两字名由公式自动补空格与三字名等宽；"待定"标红（条件格式，改掉即恢复）。

## 业务规则（已固化在脚本里）

1. **台上座次**：1 号居中。座次方向由 `layout.seat_mode` 控制：`odd_left`（默认，1 的左侧为奇数降序、右侧为偶数升序；**2025/2026 年实际采用，与 2025 版排位一致**）或 `even_left`（左侧偶数降序、右侧奇数升序）。台上自左至右顺序 = 对应半边的降序 + 另一半边的升序，1 号恒在中间。
   - ⚠️ **观众视角镜像坑**：主席台照片/截图若为观众视角拍摄，其"左右"与排位表坐标系（←西/东→）正好相反，照抄会整台镜像。2026-09-08 曾因此错排成 even_left，09-09 晚按 2025 版（odd_left，3 号紧邻校长西侧、2 号东侧，礼仪自西侧起数）纠正。收到的排位图先确认视角再录入。
2. **颁奖对位**：n 位领奖人由 1 至 n 号领导颁奖，领奖人自左至右与领导座次一一对应；左端为最大奇数号、右端为最大偶数号。
3. **校院交替**（`--leader-rule school_first`）：1 号 = 上级单位首位，2 号 = 本单位党委/行政主要负责人，3 号 = 上级单位第 2 位，其余按文档顺序（本单位在前）。
4. **台下排座**：礼堂第 1 排起留空若干排（默认前 3 排），领奖人自第 4 排起每排 6 座依次排布，按批次顺序连续编号。
5. **礼仪**：两种分配方式——
   - 自定义分组（优先）：`layout.usher_groups` 按台上左→右列出各组座次号，如 `[[12,10],[8,6],[4,2],[1],[3,5],[7,9],[11,13]]`（2026 年：13 位领导、7 名礼仪，礼仪4 专属引导 1 号葛校长），可配 `layout.usher_note` 补充说明文字；要求各组座次号按台上自左至右顺序排列，否则报错。
   - 自动分配（兜底）：`layout.ushers` 指定人数，按“台上自左至右，前 `N-礼仪数` 名各对应 2 位领导、其余各对应 1 位”分配。
   「礼仪分工表」逐名列出每名礼仪的对应领导与负责批次；说明文字统一由 `USHER_DESC` 生成，两种方式均自适应。
6. **奖级对位（一/二/三等奖）**：`items` 条目可选 `grade` 字段（如 `"grade": "一等奖"`，也支持数字 1/2/3）。任一条目带 grade 时该奖项改为按“**奖级高者对位领导职务高者**”对位：一等奖→1号、二等奖→2、3号、三等奖→4、5、6号……同级按明细顺序；领导排位不动，领奖顺序图“上台顺序”栏标注奖级并按奖级排序，领导排位图块内领奖代表按对位关系反查。无 grade 的奖项维持按台上位置依次对位（回归已验证 0 差异）。
   - **等次自动识别（parse_inputs.py）**：解析明细时自动标注 grade，支持三种来源——① 行内分组式「一等奖：心内科（张三）、呼吸科（李四）；二等奖：骨科（王五）」；② 条目标注式「骨科（王五，二等奖）」（优先级高于分组式）；③ 省科技奖团队行首的「X等奖」（如“江西省自然科学奖一等奖-…”）。解析汇总行会打印“等次：一等奖1，二等奖2”，_review.todo 首条会提示核对奖级对位。2026 真实明细已回归：仅省科技奖 3 条带等次，其余奖项不受影响。
   - **指定对位（leader_no，最高优先级）**：条目带 `"leader_no": n` 时，行序=名单顺序，行 k 的领奖人对位 leader_no[k] 号领导（须为 1..n 完整排列，否则断言报错）。**总铁律（2026-09-10 用户明令）：任何调整都不得改动已确定的领导排位——主席台 13 席与各批次颁奖领导序列模式（无等次=zig-zag）永久不动，只许调领奖人行序/对位/座位**。2026 批次⑥最终用 leader_no=[3,1,2]：周为民→3号陈超、吴永兵→1号葛校长(行2居中)、易阳艳→2号黄孝天。
   - **等次对位（默认规则，2026-09-10 定稿）**：等次 i → 从 i 号领导起顺延：一等奖→1号、二等奖→2、3号、三等奖→4、5、6号……同级按明细顺序（同级谁对 2 号谁对 3 号不敏感）。主席台席位与领奖人观众席座位均不动。无等次批次=台上位置 zig-zag（seq），两模式并存，互不干扰。
   - **块标题自适应（LEADER_SPAN）**：有等次的奖项，四处块标题（座位排布表图例/批次说明、领导排位图块头、领奖顺序图块头）显示奖级对位后的领导序列，如「对应 1-3 号（葛校长 → 黄孝天 → 陈超）」；无等次维持位置对位「对应 3-2 号（陈超 → 黄孝天）」。改 build_tables.py 后务必 grep 回读确认编辑落盘（曾出现 Edit 报成功但未生效）。
6. **三表联动**：Sheet2/Sheet3 的领导姓名、职务、座次号与领奖人姓名、科室全部是公式，引用「座位排布表」。**改表时只改座位表的单元格内容，不要插入/删除行列。**
7. **职务精简**（`--duty-style compact`）：去掉单位前缀（单位已单列在"台上单位"行），再去掉多数人共有的首段（如"院党委委员、"），避免撑爆列宽。主持人自动加"（大会主持）"。
8. **桌牌并入主表**：「桌牌打印单」A/B/C 列 = 科室/姓名/座位，B 列用 `IF(LEN=2, LEFT&"  "&RIGHT, 原值)` 公式补空格；D 列 = `座次号&". "&姓名`；「桌牌打印单(领导)」单列姓名。两字名补空不用辅助列，全部公式实现，座位表改名即同步。
9. **跳号留空（layout.skip_seats）**：`"skip_seats": ["第8排6号"]` 可让某座位号空置（后续领奖人顺延），用于末批次连排（如 2026 批次⑥连排第9排1-3号、对位 1 号者居中坐 9排2号）。绘制按座位号驱动，跳过格自动画灰。
10. **座位引用铁律**：领奖顺序图行渲染必须按**条目实际索引**（start_idx+k）取 SEAT_ADDR/seat_map，不得用行计数器 idx——等次对位/指定对位会使行序≠座位序，用行计数会错位一格（2026-09-10 修复的隐蔽 bug，此前批次 order=range(n) 未暴露）。改完代码立即 grep 落盘确认并重跑验证。
9. **礼仪分工表**：每名礼仪一行（礼仪编号 / 对应领导公式 / 人数 / 负责批次）。「负责颁奖批次」按“座次号 ≤ 该批次领奖人数的领导参与该批次颁奖”静态推算；对应领导为公式。

## 已知坑（别再踩）

- **WPS 打开打印单是空白**：模板继承了 `sheetView topLeftCell="A48"`。`build_print.py` 保存前已强制 `topLeftCell='A1'` + `zoomScale=100`，勿删。
- **WPS 生成的 xlsx 用 openpyxl 读报错** `Fill() takes no arguments`：改用 `zipfile + ElementTree` 读原始 XML，或让用户在 Excel 里另存一份。
- **openpyxl `unhashable type: 'StyleProxy'`**：不能把读到的 `cell.font` 直接赋给别的单元格，必须 new 一个 `Font(...)`。
- **输出文件被预览面板占用**：`build_tables.py` 已做 `.tmp.xlsx` + `os.replace` 回退为 `_新.xlsx`；最好先关预览。
- **议程环节名解析**：剥离尾部赘语时不要用正则把"团队"也吃掉，否则"江西省科技奖先进科技团队"会被截成"江西省科技奖先进科技"。
- **明细中的无编号标题**（如"最佳个人奖""江西省科技奖先进科技团队"）：靠"短且无冒号/顿号/括号"识别；同时必须限长 ≤20，否则"2、江西省科学技术进步奖二等奖-周为民团队-题目"会被误判成标题。
- **奖励人员无括号**（如"奖励人员：程国平、朱红、王昊"）：unit 取奖项名去掉"优秀/最佳/先进"前缀（→"在站博士后""个人奖"），不要落进上一个奖项。
